# 최단 강하 곡선 실험실

2026 경기 수학 한마당 수학 체험전 부스용 사이클로이드 시뮬레이터입니다.

## 탭 구성

1. **사이클로이드 만들기**: 바퀴가 직선 위를 구를 때 바퀴 위의 점이 그리는 사이클로이드를 보여 줍니다. 바퀴를 끌어서 직접 굴릴 수 있습니다.
2. **곡선 경주**: 직선, 원호, 포물선, 사이클로이드, 내 곡선으로 구슬 경주를 합니다. 아래 **기록 도전**에서는 내 곡선 하나만 보이고, 닉네임으로 랭킹에 기록을 남깁니다.
3. **변분법으로 찾기**: 곡선을 조금씩 고치는 과정을 반복해 사이클로이드에 다가가는 모습을 보여 줍니다.
4. **등시곡선**: 사이클로이드 그릇의 어느 높이에서 놓아도 구슬이 동시에 바닥에 도착하는지 원형 그릇과 비교합니다.

## 바로 열기

- 주소 끝에 `#race`, `#optimize`, `#isochrone`을 붙이면 해당 탭이 먼저 열립니다.

- 이 저장소(GitHub Pages 등)에서 열면 랭킹이 그 기기의 브라우저에만 저장됩니다.
